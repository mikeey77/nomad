PROJECT NOMAD - download links (as of 16 Nov 2026)
==================================================
Easiest: use Downloads inside NOMAD (resumes, installs itself).
Manual: direct links below. "(torrent)" = open with qBittorrent (free), so you can pause/resume.
For Kiwix you can also add ".torrent" to a link for the torrent version.

WORLD MAP  ->  NOMAD\data\maps\world\world.pmtiles   (~120 GB)
  https://maps.protomaps.com/builds/   -> newest .pmtiles, rename to world.pmtiles

ELEVATION  ->  NOMAD\data\maps\terrain\terrain.pmtiles   (~91 GB, torrent only)
  https://techidiots.net/downloads/open-base-map-torrents/pmtiles/jaxa_terrarium0-11/JAXA_AW3D30_2025_Terrarium_z0-Z11_cubic_webp_pmtiles.torrent
  -> open in qBittorrent, save to data\maps\terrain, then rename the .pmtiles file to terrain.pmtiles

ADDRESS SEARCH  ->  NOMAD\downloads\   (~66 GB download, ~95 GB extracted)
  https://download1.graphhopper.com/public/photon-db-planet-1.0-latest.tar.bz2
  -> then run setup again (NOMAD.exe -> tray -> Run setup); it extracts to data\search

SATELLITE: no free worldwide source found yet.
AI, PYTHON, JAVA, PHOTON: handled by the setup in NOMAD.exe.

PHONE (no server): copy NOMAD-mobile.html (in the NOMAD folder) to your phone or open it
from the SSD, then tap "Open files" and pick your .zim / world.pmtiles files.
